# PRCP-1012 · Game Winner Prediction (PUBG)

Predict the **win probability** (`winPlacePerc`, 0 = last place, 1 = winner) of PUBG players
and identify the factors that most affect winning.

## Project tasks → where they are
| Requirement | Location |
|---|---|
| Task 1 – Complete data analysis report | `notebooks/PRCP-1012-GameWinnerPred.ipynb` § 2 |
| Task 2 – Predictive model + important factors | Notebook § 3–6, `src/train.py` |
| Model comparison report | Notebook § 7, `reports/Model_Comparison_Report.md` (generated by `train.py`) |
| Report on challenges faced | Notebook § 8, `reports/Challenges_Report.md` |

All tasks are in the **single Jupyter notebook**, as the brief requires. The `src/` scripts and the
web app are the same pipeline packaged for re-use.

## Quick start

```bash
pip install -r requirements.txt

# 1. Get the data: extract PRCP-1012-GameWinnerPred.zip and copy train_V2.csv into data/

# 2. Run the notebook (main submission)
cd notebooks && jupyter notebook PRCP-1012-GameWinnerPred.ipynb    # Kernel -> Restart & Run All

# 3. (optional) Train from the command line + generate reports

python src/train.py --matches 0     # full dataset

# 4. (optional) Predict a CSV / launch the web app
python src/predict.py --input data/test_V2.csv --output reports/predictions.csv
streamlit run app/app.py
```
No dataset yet? `python src/generate_sample_data.py` creates a synthetic file so you can check
everything runs. Re-run on the real `train_V2.csv` before you submit.

## Approach
1. **EDA:** structure, missing values, target distribution, match types, univariate and bivariate plots, correlation.
2. **Cleaning:** drop the missing target, drop the inconsistent rating columns, remove cheaters/impossible rows with 10 rules.
3. **Feature engineering:** lobby-normalised kills/damage, total distance, heals+boosts, per-walk ratios, headshot rate, kill-place percentile.
4. **Group-level modelling:** mean/max/min per group + in-match percentile ranks (159 features).
5. **Models:** Linear, Ridge, Decision Tree, Random Forest, XGBoost, LightGBM. Split by `matchId`; metric is MAE.
6. **Post-processing:** rank groups within each match and snap to valid placements (used when it lowers MAE).
7. **Production pick:** LightGBM/XGBoost gradient boosting. Key factors: walk distance, kill place, boosts/heals, weapons acquired, damage.
